========================================
CAP Leaflet Editor - Pre Zákazníka
========================================

SPUSTENIE:
----------

Máš 2 možnosti:

1. NAJJEDNODUŠŠIE - Dvakrát klikni na:
   ⭐ CAP-Json-creator.vbs
   
   (Server sa spustí v pozadí, web sa otvorí automaticky)

2. ALTERNATÍVA - Dvakrát klikni na:
   CAP-Json-creator.cmd
   
   (Ukáže príkazový riadok a spustí aplikáciu)

========================================

ČO SA STANE:
-----------
1. Server sa spustí
2. Prehliadač sa otvorí na http://localhost:3000
3. Bude sa otvárať aj po reštarte počítača

PRVÝ SPUSTENIE:
--------------
- Počkaj 5-10 sekúnd na načítanie
- Ak sa prehliadač neotvorí manuálne otvorí http://localhost:3000

ZASTAVENIE:
-----------
- Zavri prehliadač
- Server beží na pozadí
- Zavri príkazový riadok (ak je viditeľný)
- Alebo znova spusti skript na reštart

========================================

POŽIADAVKY:
-----------
✓ Windows 7 alebo novší
✓ Žiadne inštalácie potrebné
✓ Potrebné je port 3000 voľný

CHYBY:
------
Ak sa aplikácia nespúšťa:
1. Skontroluj či máš dostatočné práva
2. Spusti ako administrátor
3. Skontroluj či port 3000 nie je obsadený

POMOC:
------
Kontaktuj vývojára ak je problém.
